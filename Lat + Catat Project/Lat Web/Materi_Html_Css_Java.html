html

Dasar

  • <"!DOCTIPE html"> = digunakan untuk
  • <"meta charset=UTF-8"> = digunakan agar browser menggunakan karakter universal
  • <"meta http-equiv="X-UA-Compatible" content="IE-edge""> = digunakan agar browser yang digunakan, menggunakan/memaksa browser ke versi browser baru
  • <"meta name"viewport" content="windth-device", initial-scale="1.0""> = digunakan agar browser memuat di pengaturan zoom 100% (agar tidak full page, dan ramah untuk mobile)
  • <"link name=" stylesheet" href=css/style.css(nama file/folder)"> = digunakan untuk menghubungkan/mengakses file
  • <"h1-6"> dan <"/h1-6"> = digunakan untuk membuat headline/judul/subjudul
  • <"p"> dan <"/p"> = digunakan untuk membuat paragraf
  • <"ul"> dan <"/ul>" = digunakan untuk membuat jenis list point
  • <"ol"> dan <"/ol"> = digunakan untuk membuat jenis list angka/urut
  • <"li"> dan <"/li"> = digunakan untuk mengisi data list
  • <"head"> dan <"/head"> = digunakan untuk menyetting program, yang tidak akan tampil di halaman pengguna (berisi fungsi)
  • <"body"> dan <"/body"> = digunakan untuk mengisi tampilan/informasi yang akan tampil/dapat dilihat oleh pengguna
  • <"strong"> dan <"/strong"> = digunakan untuk menebalkan teks
  • <"em"> dan <"/em"> = digunakan untuk memiringkan teks
  • <"br"> = digunakan untuk enter/memisahkan baris teks
